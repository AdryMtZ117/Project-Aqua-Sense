# AQÜA-ZENSE — Landing Page Module

Promotional and product showcase interface built with semantic HTML5, modern CSS3, and reactive vanilla JavaScript, containerized with **Nginx** on Alpine Linux.

## Component Architecture
- `index.html`: Responsive landing page and hero section.
- `style.css`: Syne and DM Sans typography design system.
- `script.js`: Interactive navigation and UI animations.
- `Dockerfile` & `nginx.conf`: Nginx static web server configuration.
